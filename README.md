# Sugestões de músicas — Esperança 2027

Página única e responsiva para receber sugestões de músicas da igreja. A interface segue a linguagem visual do projeto [caettano](https://github.com/daviavmello/caettano/).

## Como usar

Abra `index.html` no navegador ou hospede `index.html`, `styles.css` e `app.js` juntos em um serviço de hospedagem estática, como GitHub Pages.

O formulário envia os dados pelo FormSubmit para `thedavimello@gmail.com`, o mesmo endereço usado no projeto de referência. Na primeira submissão, o FormSubmit pode enviar um e-mail de ativação para esse endereço. Confirme o e-mail para habilitar o recebimento. Para trocar o destinatário, atualize a URL do `action` em `index.html` e a constante `endpoint` em `app.js`.

Os campos obrigatórios são o nome da música e o link do vídeo. Comentários adicionais são opcionais.
